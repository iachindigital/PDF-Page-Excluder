# PDF-Page-Excluder
PDF Page Excluder

DEMO: https://iachindigital.github.io/PDF-Page-Excluder/index.html

PDF 智能页码计算器 (PDF Page Calculator)
这是一个轻量级、现代化的纯前端 Web 工具，旨在帮助用户快速计算 PDF 文档中需要打印的页码范围。

无论是想要排除不需要的页面（黑名单模式）还是精准指定需要打印的页面（白名单模式），该工具都能实时响应并自动将连续的页码压缩成可以直接复制到打印机对话框中的格式（如：1-3, 5, 9-99）。

🚀 功能特点
双模切换：支持“排除不需要的页（黑名单）”与“仅打印指定页（白名单）”两种模式自由切换。

实时动态计算：无需手动点击按钮，输入总页数或页码时结果即刻刷新。

智能格式清洗：支持中英文标点自动转换（如全角逗号 ，、全角减号 －），并能自动忽略末尾悬空的逗号或连字符。

奇偶页筛选：支持一键快速筛选“全部”、“仅奇数页”或“仅偶数页”，完美适配双面打印需求。

常用快捷模版：内置“去除首页”、“去除前3页”、“去除首尾”等一键填入快捷键，提升办公效率。

精美暗黑 UI：采用现代 Tailwind CSS 构建的暗黑风格界面，保护视力且极具科技感。

零配置部署：纯前端单文件（HTML + JS），开箱即用，完美兼容 GitHub Pages。

🛠 如何使用
输入总页数：在“PDF 总页数”输入框中填入 PDF 的总页码。

输入页码范围：根据当前模式输入对应的页码。支持：

单页：5

连续区间：4-10

混合输入：1-3, 5, 7-10

复制并打印：点击“复制”按钮，将生成的优化页码粘贴到 PDF 阅读器或浏览器的打印设置中即可。

💻 部署到 GitHub Pages
将此项目文件保存为 index.html 并提交到你的 GitHub 仓库中。

进入仓库的 Settings -> Pages。

在 Build and deployment 下的 Branch 栏目选择你的主分支（如 main 或 master），目录选择 / (root)，点击 Save。

等待片刻后，即可通过 GitHub 自动生成的专属链接访问你的在线计算器。
